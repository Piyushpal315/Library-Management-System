# Library Management System

A console-based Library Management System developed in C++ using Object-Oriented Programming (OOP) concepts.

## Features

- Add and manage books
- Search books
- Issue and return books
- Manage library users
- Librarian and staff management
- Maintain library records
- Fine management

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- File Handling

## OOP Concepts Used

- Classes and Objects
- Inheritance
- Encapsulation
- Abstraction
- Polymorphism

## How to Run

1. Download or clone this repository.
2. Compile the C++ source files using a C++ compiler.
3. Run the generated executable.
4. Follow the menu options displayed in the console.

## Project Structure

The project contains separate classes for Books, Users, Staff, Librarians, Accounts, and Library Database management.
